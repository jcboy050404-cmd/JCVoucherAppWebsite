Changelog v1.1.6

✨ New Features & Enhancements

License Keys & Resellers:

  • Added a License Key Redemption system for easy PRO activation.
  • Introduced a Super Admin Panel to generate, track, and copy reseller keys.
  • Added a Remote Kill Switch to securely manage active PRO subscriptions.

Core App Features & Analytics (v1.1.2):

  • Added support for Remote Config and accessing files directly on MikroTik.
  • Introduced Revenue Trend tracking to easily monitor sales.
  • Added Automated SMS Reminders for improved user engagement.

Template & PDF Improvements:

  • Added targetTicketsPerPage and hotspotName support to all PDF templates.
  • Updated standard template and UI for customizing tickets per page.

🐛 Bug Fixes

  • Closed device-limit race condition and prevented offline bypass vulnerabilities.
  • Fixed a Trial reset bug: Resetting the trial used state when downgrading a PRO user back to free trial.
  • Fixed duplicate cellH variable declaration in PDF rendering.

Older Changelogs v1.0.0 - v1.0.1

✨ New Features & Enhancements

Template & Voucher Improvements:

  • Added a new logo and color customizer modal to the Premium Split template.
  • Adjusted the layout for the Premium Split template and removed redundant voucher text.
  • Dynamically updated the voucher label to display "User Login" whenever a password is provided.

Build & Automation:

  • Automated the APK export format to dynamically append the version number (e.g., Voucherapp_v1.0.1.apk) to the build path.

🎨 UI & UX Improvements

  • Upgraded overall app aesthetics by implementing extensive Glassmorphism UI blur effects.
  • Redesigned the Force Update Dialog to feature a transparent background with a modern glassmorphism effect.
  • Various small UI adjustments and screen optimization updates across the application.

🐛 Bug Fixes

  • Fixed an infinite loop bug related to the Force Update mechanism.
  • Fixed syntax and layout errors in the Force Update dialog.
  • Resolved an asynchronous bug in the admin screen that prevented the UI from updating immediately after approving a user.
  • Optimized the login shield behavior and fixed cloud revocation synchronization issues.
